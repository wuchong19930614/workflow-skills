## 1. 通道分工

| 用途 | 通道 | 原因 |
| --- | --- | --- |
| Semrush 各模块 | 当前环境的 Chrome 控制工具，复用用户已登录的 Semrush 标签页 | 需要登录态 |
| Google SERP 现场、读标杆站页面 | 内置浏览器面板（美区、桌面、未登录） | 避免登录个性化 |
| RDAP 注册日、`ads.txt`、`robots.txt`、`llms.txt` | `curl` | 不需要浏览器 |

SERP 只用通过预检的内置面板，不用已登录 Google 的 Chrome 代替。连续运行由主会话亲自执行 Semrush 部分：子代理访问 Semrush 曾被自动模式分类器拦截，被拦时不要转达授权重试，停下问用户（加放行规则，或切"逐条询问"模式）。

## 2. Semrush

### 2.1 额度纪律

- 每次查询都要能改变一个决策；决策不变，查询不跑。
- 代理站每天约一百来次查询，域名类与关键词类分开计。预计单日超过约 100 次时分天跑，先查最关键的。
- 每条运行清单如实记 `semrush_calls`（本条新增数）；每份观察也记本观察新增的 `semrush_calls`。
- 登录失效、验证码、额度提示 → 停下写 blocked 清单，不绕、不猜数。

### 2.2 各模块怎么用

| 用途 | 模块与做法 |
| --- | --- |
| 粗筛 AS 与流量（scan） | 批量分析，每批 ≤ 16 个域名。页面刚载入时同一批次内的输入都不生效，要另起一次调用再输；超过约 15 行时比较按钮会下移，用 find 拿元素引用点击。这里的"每月访问量"是全球全渠道，只用来粗筛 |
| B2、B3 与流量曲线（scan/assess） | Domain Overview（美区）：域级 AS、美区自然流量、流量曲线（读起量月、第 3/6/12 个月、2026 年 3/6/8 月更新前后）。B3 用"去掉品牌词与 near me 类定位词后"的流量：在 Organic Research（美区）里排除品牌词与定位词后取合计，basis 写筛法 |
| 英文区换算（scan/assess） | Domain Overview 的按国家分布：记英文区 6 国（US、GB、CA、AU、NZ、IE）的原始自然流量到 `country_traffic`，`en_* = 美区读数 × 6 国合计 ÷ 美国`，不多花调用；美国为 0 时不能按比例换算，改用各国的 Organic Research 实测并写进 basis |
| 域名分析模块故障时 | 改走 `/analytics/backlinks/overview/?q=<域名>&searchType=domain`，同样给 AS、每月访问量与自然流量；曲线也拿不到 → parked |
| 起量手段（assess） | Backlink Analytics：引荐域名数、锚文本分布、引荐域名质量 |
| 标杆排名词、对手按网址筛流量（assess） | Organic Research。筛选写在网址的 filter 参数里（URL 编码的 JSON，如 `{"search":"/county/",...}`），可直接拼网址；页面刚载入时输入会被吞，读表头前等 8–10 秒 |
| 同类站（sibling） | Organic Research 的"竞争对手"列表 |
| 簇量（assess） | 每簇种子词用 Keyword Overview 取 6 国月量填 `seed_country_volume`（每簇多 1 次调用），`en_volume = 美区簇量 × 6 国合计 ÷ 美国`。Keyword Magic：US、phrase match。种子只用名词性主题词；量地方查询时不要排除导航意图。长尾簇可导出 CSV（下载要用户当次允许；放进 scratchpad 的独立目录，用 `python3 -I` 解析） |

## 3. 免费来源

- **RDAP 注册日**：`curl -s https://rdap.org/domain/<域名>`，取 `events` 里 `eventAction=registration` 的日期。404 表示查不到，B1 改看 Semrush 曲线并标 `aged_domain`。
- **变现方式**：`curl -s https://<域名>/ads.txt` 看广告网络（google.com=AdSense，ezoic、mediavine、raptive/adthrive 等）；找 `/pricing` 或页脚里的付费入口。被 Cloudflare 拦时改读 Google 摘要并注明。
- **GEO 现状**：`curl -s https://<域名>/robots.txt` 与 `/llms.txt`，看标杆是否放行 AI 爬虫。
- **手工种子**：往 `种子/手工种子.json` 写域名前，先用 RDAP 确认域名存在；查不到的不写。

## 4. Google SERP 读取规程

### 4.1 环境与预检

- 内置浏览器面板、未登录；搜索网址显式带 `https://www.google.com/search?q=<查询>&gl=us&hl=en&pws=0`。
- 每次读 SERP 前核对四项，写进 serp 观察的 `browser_preflight`：

| 项 | 怎么核 |
| --- | --- |
| `controllable` | 能读到完整页面，含自然结果上方区域 |
| `desktop` | `#rcnt` / `#center_col` 在场，或 UA 与布局为桌面版 |
| `region` | 网址三参齐备 → `us`；页脚位置写进 `evidence`，不凭 `gl` 声称美国 IP |
| `logged_out` | 页面有 `Sign in`，没有 Google 账号头像元素 |

- 任一不合规 → 不写 `answered` 结论；重试一次仍失败记 blocker。
- 两次 Google 请求间隔 ≥ 60 秒；几分钟内 7–8 次会触发 /sorry。

### 4.2 读什么

- AI 概览在页面载入后异步生成：等几秒再读整页；出现 `Thinking`、`Searching` 时继续等；没看到 `AI Overview` 字样时隔几秒重读一次确认。
- 只返回自然结果列表时，不能据此判断没有 AI 概览，要补读整页或截图。
- 记：AI 概览/精选摘要/原生组件是否已完成任务（`answered` 与 `answered_basis`）、AI 概览引用的域名（`cited_domains`）、是否点名推荐工具站（`recommends_tools`）、标杆排第几（`benchmark_position`，不在前 10 填 null）、前 10 条自然结果（位置、域名、类型、AS）。
- 判"已完成任务"看的是：用户不点结果是否已拿到要的东西。单个查询只有一个答案的（某车型的孔距、某城市的时区）通常会被答掉；单个查询有多个可能答案、要按地点或型号再查的（这趟车几点、这个地址属于哪个县）通常答不了。

## 5. 旧数据导入规则

`seed_import.py --legacy-root <xinci-simple 数据区>` 只读导入，幂等：

- **标杆种子**：旧证据 `serp_top10` 里有 AS 记录、最小 AS < 30 的域名。排除：`.gov/.edu/.mil` 及域名标签以 gov 结尾的政府域名；出现过 official/brand/forum/video 类型的；平台黑名单。AS 记为 0 的当作未测，照样导入、初核时重测。
- **平台黑名单**（`seed_import.PLATFORMS`，增删须在本节写理由）：pinterest.com、play.google.com、scribd.com、reddit.com、facebook.com、youtube.com、quora.com、amazon.com。
- **同类站种子**：旧账本里 `seed.type=small_site` 的种子文字里出现的域名，`role=sibling`，只用来查同类站。
- **手工种子**：`种子/手工种子.json` 里的条目最先导入；不满足 B2、只用来查同类站的写 `"role": "sibling"`，默认 `benchmark`。
- **旧词库/旧裁决**：旧账本全部逐词量（按小写词去重，保留测量更晚的那条）与 63 个候选的终态、gate、理由，供 `lexicon.py` 查询。
- 导入前后对读过的旧文件逐个算 SHA-256，不一致就报错停止。

## 6. 已知的坑

- 代理站对超宽泛种子返回截断数据；对介词或疑问短语种子（`substitute for`、`why is my`）返回残缺数据集。
- Semrush 对 near me 词按单一抓取点估流量，会把全国量算给一个城市页，不能当真实分流。
- 竞品在某个州或某类页面上的流量，要在"主要页面"或 Organic Research 里按网址筛选再加总；从全站前 100 页里挑会严重低估。
- Chrome JS 返回超过约 1,000 字会截断，含 `=` 或 `location.href` 会被拦；长表分段读。
- 同一会话第二次起 Chrome 可能拦"多次下载"，要用户在 Chrome 里允许；翻页可替代导出（每页 100 行算 1 次调用）。
- 面板和 Chrome 的出口 IP 不在美国，部分站被 Cloudflare 拦。
- 写观察前先用 `date -u +%Y-%m-%dT%H:%M:%S+00:00` 取系统时间，不要估。

## 7. 快道数据来源

2026-10-13 从本机逐个实测。未在本次运行实际取回的来源不得写"已检查"；实际打开的网址记进观察 `source_urls`。

### 7.1 快道的通道分工

| 通道 | 用于 |
| --- | --- |
| curl / 脚本 | 自动补全（`suggest_snapshot.py`）、Trends 热搜 RSS、各公开接口与订阅源 |
| 内置浏览器 | Trends 曲线与飙升词（在 trends 页面里调用内部接口）、Google 首页、Reddit（经 Google 搜索）、Google Play |
| 用户的 Chrome | 用 Semrush 查锚词月量：美国只在旧词库没有合适锚词时查；美国以外的国家一律要查（旧词库只有美国的量） |

社区类条目（Product Hunt、Reddit）有潜力的要在真实浏览器读原页，看人们怎么称呼它。

### 7.2 搜索侧

| 来源 | 获取方式 | 取什么 | 限制与实测 |
| --- | --- | --- | --- |
| Google 自动补全 | `suggest_snapshot.py --object "<对象名>" [--gl gb]`：请求 `https://suggestqueries.google.com/complete/search?client=firefox&hl=en&gl=<国家>&q=<查询>`，默认美国；英国、加拿大、澳大利亚等地区性对象（当地新规、当地服务器）加 `--gl`，各国快照分开存；返回 `[原查询, [≤10 条建议]]` | 对"对象名 + 空格"和"对象名 + 每个任务词"各取一次；快照存 `快道/补全快照/`，以前所有快照里都没出现过的才算新说法，并给出与上次的间隔天数 | 可用。**同一查询隔几秒请求两次结果也会不同**，所以只认"从没出现过"；频率上限未确认，脚本间隔 1 秒；取数失败不写快照 |
| Trends 曲线 | 内置浏览器打开 `https://trends.google.com/trends/explore?geo=<国家代码>&q=<词>`（英文区 6 国 US、GB、CA、AU、NZ、IE 各查一次），页内 `fetch('/trends/api/explore?hl=en-US&tz=0&req=<JSON>')`，切掉返回体前缀 `)]}'`，取 `TIMESERIES` 的 request 与 token，再请求 `/trends/api/widgetdata/multiline?req=…&token=…` | `timelineData[].value`；`now 7-d` 逐小时、`today 1-m` 逐日、`today 3-m` | 可用；两次请求间隔 ≥ 1.5 秒，curl 直接请求 429 |
| Trends 飙升词 | 同上，取 `RELATED_QUERIES` 的 request 与 token，请求 `/trends/api/widgetdata/relatedsearches` | `rankedList[0]` 热门、`rankedList[1]` 飙升（百分比或 Breakout）；对新对象查，也对任务词以 `now 7-d` 查 | 可用；如 "grow a garden 2 weather tracker" +200% |
| 锚词换算 | 同上，每个国家一次请求，放新词与锚词两个 `comparisonItem`（`geo` 都设为该国，`today 1-m`） | 两条曲线最近 7 天与 30 天均值 → `quick_model.anchor_estimate`；6 国换算量相加 | 每国比值须 0.2–5，不合就给该国换锚词；读不出的国家写 `readable=false` 记 0；低量词是噪声大的小整数 |
| Trends 热搜 RSS | `curl https://trends.google.com/trending/rss?geo=<国家代码>`，6 国各取一次 | `title`、`ht:approx_traffic`、`ht:news_item_title`、`ht:news_item_url` | 可用；基本是新闻，主要用来判 Q3 新闻热点 |
| Semrush | 用户 Chrome，Keyword Overview（选国家，或看按国家的分布） | 锚词在各国的月量 | 一次能否看全 6 国未实测；新词自身量多久出现未确认，首次运行时测 |

### 7.3 上游新对象

| 来源 | 获取方式 | 取什么 | 实测 |
| --- | --- | --- | --- |
| SteamCharts（代替 Steam） | `curl https://steamcharts.com/top`（HTML 表）；单款 `https://steamcharts.com/app/<id>` | app id、名称、当前在线人数；与上次比出新进榜；单款在线人数走势。无发布日期，Q1 改从 Wikipedia 或 Google 读 | 可用 |
| Roblox | 不直接取：用自动补全与 Trends 盯 "roblox" 加任务词的飙升，再看 YouTube | 新体验名与任务说法 | 官方与第三方统计站都取不到 |
| Apple 免费榜 | `curl https://rss.applemarketingtools.com/api/v2/us/apps/top-free/50/apps.json` | `name`、`releaseDate`、`url`（`genre` 过滤无效，游戏不能单独筛） | 可用 |
| iTunes 搜索 | `curl "https://itunes.apple.com/search?term=<词>&country=us&entity=software"` | `trackName`、`releaseDate`、`primaryGenreName`；核发布日期、看有没有配套 App | 可用 |
| Google Play | 内置浏览器读 `https://play.google.com/store/games?hl=en&gl=US` | 新上榜游戏名 | 未实测 |
| Product Hunt | `curl https://www.producthunt.com/feed`（Atom） | `title`、`link`、`published`、`content` | 可用 |
| GitHub | `curl "https://github.com/trending?since=daily"`；`gh api "search/repositories?q=created:>YYYY-MM-DD&sort=stars&order=desc"` | 仓库名、`created_at`、`stargazers_count` | 可用；未登录搜索每分钟 10 次 |
| Hacker News | `curl "https://hn.algolia.com/api/v1/search_by_date?tags=show_hn&numericFilters=points>50"` | `title`、`url`、`points`、`created_at` | 可用 |
| YouTube 搜索 | `curl "https://www.youtube.com/results?search_query=<词>"` | 页面内视频条目数与发布时间（相对时间），看创作者是否跟进 | 可用但易碎，出口不在美国，页面为繁体中文（香港） |
| Wikipedia 浏览量 | `curl https://wikimedia.org/api/rest_v1/metrics/pageviews/per-article/en.wikipedia/all-access/user/<词条>/daily/<YYYYMMDD>/<YYYYMMDD>` | 每日 `views`，对象热度的绝对参照与持续性 | 可用 |
| 平台规则与政策 | `curl "https://www.federalregister.gov/api/v1/documents.json?order=newest"`；其他辖区见旧新词工作流 `数据采集指南.md` | `title`、`publication_date`、`type`、`abstract` | 可用 |

### 7.4 现场

- Google 首页：同第 4 节规程（美区三参、预检四项、请求间隔 ≥ 60 秒）；Q5、Q6 只看美国首页（用户 2026-10-14 定）。
- Reddit：接口返回 403；内置浏览器搜 Google `site:reddit.com "<对象>" (calculator OR tracker OR tool)`，加 `tbs=qdr:w` 只看过去一周。

### 7.5 确认不可用

Steam 官方接口（curl 连接失败、内置浏览器被拒、Chrome 错误页）、SteamSpy（Cloudflare 挑战）、Roblox 官网与接口（三条通道都打不开）、RoMonitor 与 RoTrends（curl 只得脚本外壳）、Reddit 接口（403）、Trends 接口直接 curl（429）、Google 搜索页直接 curl（脚本外壳）。Exploding Topics 等付费趋势工具没有账号，不用。
