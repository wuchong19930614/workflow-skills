## 规范性附录 B:每转移的证据要求(registrar 校验逻辑)

| 转移 | 必须提供且校验 |
| --- | --- |
| register(→captured) | slug、term(精确措辞)、source.url、task、≥1 个 evidence 文件(存在于磁盘) |
| captured→screened | gates G1–G5 全部 `pass`;window_estimate ∈ {days,weeks,months};≥1 evidence |
| *→rejected | reason(失败闸门 + 现场证据要点) |
| screened→tracking | expiry(YYYY-MM-DD 可解析)+ invalidation ≥1 条 + ≥1 evidence |
| screened→fast_grab_ready | decision_ref 指向存在的 md,且同名 .html 同时存在(7.3 双格式);expiry;play=fast_grab |
| tracking→formation_confirmed | 候选已有 ≥2 个文件名含 `-track` 的证据;本次 gates.G1=pass;≥1 evidence |
| tracking→expired | reason(expiry 已过经用户确认 / 失效条件命中) |
| formation_confirmed→qualified | score ≥80(整数)+ gates G6/G7/G8 全 `pass` + ≥1 evidence |
| formation_confirmed→disqualified | reason(决定性缺口:哪一项、差多少) |
| qualified→build_ready / pilot_ready | decision_ref md+html 双文件存在;play ∈ {single_domain, cluster_expansion} |
| qualified/hold→hold / no_site | reason;**不得**携带 decision_ref(no-go 不出决策书) |
| built→tracking | reason(升级理由)+ 新 expiry |
| *→withdrawn | reason |
| *→superseded | superseded_by(账本中已存在的 slug) |
| checked(非转移) | 更新 last_checked_at、追加 evidence,不改 state |

证据文件路径一律相对 `数据/新词工作流/`;命名约定 `证据/<slug>/<YYYY-MM-DD>-<阶段>.json`,阶段 ∈ {scan, track, qualify, decide}。
