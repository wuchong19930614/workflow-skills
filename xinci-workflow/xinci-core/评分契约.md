# 评分契约(认定阶段)

仅适用于 `formation_confirmed → qualified` 的正式认定,由 xinci-qualify 执行。窗口期与形成期不评分。

## 计分

```
final_score = max(0, 六维得分合计 - 红队扣分)
过线:final_score >= 80(整数)
```

**79 分不算过。** 不为凑候选降门槛;分数差多少如实写进 disqualified 的决定性缺口。

## 六维权重(合计 100)

| 维度 | 分值 | 判据 |
| --- | --- | --- |
| 触发真实性 | 15 | 有日期的原始变化 + 独立佐证;时机仍在影响任务 |
| 任务价值 | 12 | 按实际通过线评价需求：订阅看重复使用，线索看可成交服务需求，交易/报告看单次付费事件，推荐/广告看购买或持续信息需求；不要求所有模式都重复付费 |
| 搜索语言形成 | 8 | 独立证据显示受影响的人用可搜索的自然语言表达该任务 |
| 竞争 | 30 | exact-task 完成度与直接产品成熟度为主;竞品实际占据 footprint(流量、覆盖词量、增速)只占小头;KD / Authority Score / 外链数不计分 |
| 变现对齐 | 15 | 搜索者与付费者的关系、自助交易路径明确 |
| 收入可行性 | 20 | 按 G6 实际通过的六条盈利线评分。每条通过线都写付费者、付费事件/重复单位、交付物、保守单价与数量、收入算式、出处及最大反证。subscription 无统一金额硬线;advertising 的 $200/月只约束广告线;lead_generation / transaction / paid_report 可由少量高价值需求成立;affiliate 需流量与购买意图证据 |

计分纪律:

- 新颖性本身不挣分。触发、任务、语言各自取证；缺少重复付费不能把独立成立的触发与搜索语言一并清零。
- 大受众但没有搜索语言证据,语言形成最多给 2/8。
- 竞争 30 分里,exact-task 完成度与直接产品成熟度占大头;确认期实测的流量、覆盖词量、增速只作"实际占据"小头。域名强度代理不计分、不得改写 G2/G3(口径与依据见闸门契约「关于 KD / KGR / allintitle 的统一立场」)。
- **收入可行性不得为 0/20**(依据:校准 §9.3、§15.1)。registrar 要求 `--income-score 1..20`,账本同时记录 `g6_passed_lines`;未通过任何盈利线不得评分。低收入分降低总分，但不保证总分低于 80：其余五维满分 80，加收入 1 分仍为 81。认定通过证明机会达到当前标准，决策阶段仍须按收入三情景与投入判断是否值得做；本次不新增统一收入门槛。

## 分档锚点

六维权重与 80 分线不变。每维独立取证，按以下锚点给整数分并在 points 说明依据：无支持事实为 0；仅间接迹象通常不超过该维一半；有直接证据但关键假设仍较弱为约 50–75%；独立直接证据且合理敏感性范围内成立为约 75–100%。决定性未知先暂缓，不适用“无证据给零分”。锚点是初始校准口径，不声称已用成功样本验证。

六维分别回答：变化是否真实、任务是否有价值、搜索语言是否形成、剩余任务是否有竞争空间、搜索者如何到达付费事件、保守收入是否可行。风险只计入最直接受影响的一维。

## 红队扣分

评分完成后检查遗漏风险。每个事实使用唯一 risk id，只记到一个维度或 red_team；已计入维度的影响不能再次红队扣分。一次性任务只有在所选盈利线依赖复购时才构成风险。多个独立影响须分别说明因果，不许换 id 重复扣同一不确定性。结构见证据判定契约；总分由 qualification.py 计算。

## 硬约束

- 硬否决之后**不得**产生最终分数,没有"高分但被否决"这种记录。硬否决包括:
  - G0 / G1 / G4 命中;
  - G2 结构阅读结论为否;
  - G3 判 `veto`(占位否决按盈利线生效时,含陷阱类别的有效 G3 验证失败;生效口径见闸门契约 G3「前置:G3 的否决只对"靠自然位吃流量"的模式生效」);
  - G5 有充分证据命中直接筛除判据，或现场验证产生有效否决；尚未验证不是否决;
  - 认定三道 G6–G8 任一有充分证据判为 veto，才按硬否决 disqualified；尚未取得通过证据按公共证据契约处理。
- 进入 screened 的条件以 registrar 强制为准:G0/G1/G2/G4/G5=`pass`,且 G3=`pass` 或按口径判出的 `veto_window_bet`。后者只走快道,快道本身不评分(见闸门契约 G8)。
- veto 被推翻的候选回到普通评分,不因此豁免任何数值闸门。
- 证据缺失、代理口径及暂缓到期统一按[证据判定契约](证据判定契约.md)执行。未解决的决定性缺口不出分；已证明的硬否决不被其他缺口阻挡。
- `final_score ≥80` 与 `income_score ≥1` 必须同时满足;前者不能替代后者。
