# 陷阱速查

本表只负责快速路由，不替代 [陷阱类别.md](陷阱类别.md) 的完整判据。扫描先读本表；疑似命中时再读取完整文件中对应类别，确认检查要点、适用边界与出口后才能处置。

## 两种处置

- **直接筛除型**：命中完整类别判据后按 G5 追加淘汰索引，不开 SERP。
- **验证型**：命中只改变检查顺序，仍须跑指定的 G3/G1 现场验证；先按盈利线判断占位否决是否生效。

| 类别 | 快速识别信号 | 处置 |
| --- | --- | --- |
| 1 新发布 AI 模型 | 新模型的 VRAM、量化或部署查询 | 验证型：实测通用工具覆盖与收录时差 |
| 2 纯品牌名发布 | 只有导航或“这是什么”，没有页面可完成的任务 | 直接筛除 |
| 3 厂商已占位的 B2B 强制任务 | 付费者明确且已有对应 SaaS、律所或厂商内容机器 | 验证型：查官方答案和具体占位 |
| 4 厂商 release note 衍生任务 | 来源是厂商自己的 changelog，任务是怎么用新功能 | 验证型：核实具体交付与剩余任务 |
| 5 观点、新闻与旧文回流 | 高热度但没有具体页面可完成的任务 | 直接筛除 |
| 6 管辖机构自维护对象全集 | 每个对象已有官方页或权威数据库记录 | 验证型：实测一个对象查询 |
| 7 横向对比与迁移 | alternatives、X vs Y、migrate off X | 验证型：查目录、榜单与成对对比站 |
| 8 厂商不利的开关型任务 | 关闭、退出、删除厂商默认行为 | 验证型：按任务与逐线证据判断 |
| 9 零回答与悬赏问题 | 孤立提问、冷门遗留技术、没有重复独立需求 | 验证型：按任务与逐线证据判断 |
| 10 参数发布方连带供给答案 | 参数发布者同时提供表、公式、工具或免算路径 | 验证型：检查实际任务覆盖与剩余付费事件 |
| 11 持牌机构合规义务 | 法律责任需要能签字的人；自助交付效力不足 | 直接筛除前仍须检查其余盈利线 |
| 12 AI Overview 接管横向汇总 | 首屏可合成公开规则、公式或小决策树 | 验证型：逐措辞实测 G1 |
| 13 发证/受理方自带对象工具 | 官网、后台、Excel、登记册或解释例表可吃对象出结果 | 验证型：核实交付，不按主体身份推断 |
| 14 新旧法规过渡条款 | 一条时间线加少量统一例外，没有多维逐对象判定 | 验证型：按任务与逐线证据判断 |

## 使用边界

- 表中信号只用于定位类别，不能单独生成 G5 结论。
- 验证型类别读取对应完整类别；商业预筛已有充分否决证据时可先结束，否则按需现场验证，已有有效证据可复用。
- 类别 11 只能否决实际受法律效力约束的盈利线；六条适用线全部否决或所有声称交付均依法无效，才可否决整候选。
- 新模式先形成提案；新增或改写通用类别必须经用户确认，不在 xinci-run 标准授权内。
