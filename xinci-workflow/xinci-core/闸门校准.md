# 闸门校准索引

本文件只保留运行时需要知道的校准状态。历史回测、旧规则、案例与逐轮修订记录已移到
[history/闸门校准历史.md](history/闸门校准历史.md)。历史材料只用于审计和解释来源，**不定义现行口径**。

## 正本边界

- G0–G8：以 [闸门契约.md](闸门契约.md) 为准。
- 状态、转移、授权与终止：以 [生命周期契约.md](生命周期契约.md) 为准。
- 浏览器、来源与 Semrush：以 [数据采集指南.md](数据采集指南.md) 为准。
- 陷阱识别与处置：以 [陷阱类别.md](陷阱类别.md) 为准；运行时先读 [陷阱速查.md](陷阱速查.md)。
- 分数：以 [评分契约.md](评分契约.md) 为准。

契约引用“校准 §N”时，节号均指历史文件。不要为了执行当前工作流加载历史全文；只有核对某条规则的来源、准备修改契约或执行 calibration 轮时才读取对应小节。
